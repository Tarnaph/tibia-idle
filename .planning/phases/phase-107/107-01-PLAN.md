# Phase 107 — Plan 107-01: Diferimento da Entrada e Visibilidade do Personagem até o Fim do Loading

## Objetivo
Garantir que:
1. O personagem NUNCA seja colocado em uma zona de caçada perigosa enquanto a tela de carregamento (ExuraLoadingScreen) estiver ativa.
2. O loop de combate (`tickCombat`) fique 100% bloqueado enquanto qualquer loading estiver ativo, garantindo 0 ticks de combate, 0 monstros se aproximando e 0 dano recebido enquanto o jogador não estiver vendo a tela do jogo.
3. O personagem fique visualmente oculto (`isCharacterVisible = false`) em `ThaisCityArena` e `PixiArena` durante a tela de loading, surgindo no mundo exatamente junto com o término da tela de carregamento (100% / `onFinish`).
4. Ao viajar para uma caçada (`startSelectedHunt` ou `onPartyHuntStart`), o teleporte, o `restartHunt` e a ativação de combate sejam diferidos via `pendingHuntTransitionRef` para executar com segurança apenas no callback `onFinish` do loading.

## Modificações
1. `apps/web/components/GamePrototype.tsx`:
   - `pendingHuntTransitionRef`: Guarda parâmetros da hunt pendente.
   - `isCharacterVisible`: Calculado como `!initialLoadingActive && !transitionLoading?.active`.
   - `tickCombat`: Adicionar trava `if (initialLoadingActive || Boolean(transitionLoading?.active)) return;`.
   - `tickCityAutoSpells`: Adicionar trava `if (initialLoadingActive || Boolean(transitionLoading?.active)) return;`.
   - `startSelectedHunt`: Salva progresso, abre loading de 10s e enfileira transição na `pendingHuntTransitionRef`. Se já em hunt, executa `leaveHunt` preventivo.
   - `unsubHuntStart`: Trata entrada de membros de party com o mesmo diferimento seguro.
   - `ExuraLoadingScreen.onFinish`: Executa a transição pendente (se houver), atualiza `cityPos`, teleporta, define `mode = 'hunt'`, redefine `lastCombatTimeRef` e ativa a visibilidade.
   - Passa `isCharacterVisible` para `PixiArena` e `ThaisCityArena`.

2. `apps/web/components/PixiArena.tsx`:
   - Adicionar prop `isCharacterVisible?: boolean` (default: true).
   - Ocultar party actors (`view.root.visible = latestRef.current.isCharacterVisible !== false && actor.alive`).
   - Ocultar `targetReticle` quando `isCharacterVisible` for false.

3. `apps/web/components/ThaisCityArena.tsx`:
   - Adicionar prop `isCharacterVisible?: boolean` (default: true).
   - Ocultar o ator local `localChar` (`view.root.visible = latestRef.current.isCharacterVisible !== false`) enquanto `isCharacterVisible` for false.

4. `tests/phase107-character-spawn-post-loading-safety.test.ts`:
   - Testes unitários cobrindo o bloqueio de combate durante loading, diferimento da transição de hunt e visibilidade pós-loading.

# Phase 70 - Plan 01: Botão de Mandar Mensagem e Ações Diretas na Lista de Amigos

## Objetivo
Adicionar o botão explícito e direto de "Mandar Mensagem" na lista de amigos (`FriendsWindow.tsx`), permitindo que o jogador clique diretamente para enviar mensagem privada para qualquer amigo (online ou offline), acompanhado de barra de ações rápidas para o amigo selecionado e integração com o chat do jogo para pré-preencher o whisper canônico (`*Nome* `).

---

## Detalhamento Técnico

### 1. Atualizações em `apps/web/components/window/FriendsWindow.tsx`
- **Ações Rápidas em Cada Linha de Amigo**:
  - No card de cada amigo (online e offline), adicionar botões de ação compactos e visualmente refinados:
    - Botão `[ 💬 Mensagem ]` (ou `💬` com tooltip de alta visibilidade "Mandar mensagem"): aciona `onPrivateMessage(friend.name)` diretamente sem necessidade de menu secundário.
    - Botão `[ ⚔️ Party ]`: aciona `onInviteParty(friend.name)`.
- **Barra de Ações do Amigo Selecionado**:
  - Quando o jogador clica em um amigo da lista para selecioná-lo, exibir um painel inferior de ações rápidas:
    - Exibe: `Amigo selecionado: {selectedFriend.name} (Lv. {selectedFriend.level})`
    - Botão de destaque `[ 💬 Mandar Mensagem ]` (botão com visual vibrante e fácil de clicar).
    - Botão `[ ⚔️ Convidar para Party ]`.
    - Botão `[ ❌ Remover ]`.
- **Menu de Contexto**:
  - Manter as opções completas ao clicar com botão direito.

### 2. Aprimoramento em `apps/web/components/chat/ChatWindow.tsx`
- Atualizar `ChatWindowHandle`:
  - Permitir que `focusInput` receba um parâmetro opcional `prefillText?: string`:
    ```ts
    focusInput: (channel?: 'local' | 'world', prefillText?: string) => void;
    ```
  - Quando fornecido, atualizar `inputText` para o texto formatado (ex.: `*Nome* `) e posicionar o foco do teclado no input.

### 3. Integração em `apps/web/components/GamePrototype.tsx`
- No callback `handlePrivateMessage(name: string)`:
  - Abrir a janela de chat (`openWindow('chat')`).
  - Trazer o chat para o primeiro plano (`bringToFront('chat')`).
  - Chamar `chatWindowRef.current?.focusInput('local', `*${name}* `)`.
  - Exibir notificação de feedback na tela: `Conversando com ${name}...`.

### 4. Testes e Validação
- Criar `tests/phase70-friends-message.test.ts`.
- Executar `npm run typecheck` com 0 erros.
- Validar no Vitest com 100% de aprovação.

# Phase 249 Plan: Abertura da Janela de Seleção de Venda Rápida de Loot no Mobile via Botão Flutuante

## 📋 Contexto & Diagnóstico
- **Problema Relatado:** No mobile, o botão flutuante de venda rápida (`MobileQuickSellBubble`) acende e exibe o badge de contagem de itens, mas ao ser pressionado nada visual acontece. O jogador precisa que ele abra a tela interativa de loot para escolher o que será vendido, exatamente como ocorre na versão web desktop.
- **Causa Raiz Identificada:** Em `GamePrototype.tsx` (linha 5178), o componente `<MobileQuickSellBubble>` recebia a prop `onQuickSell={sellLoot}`. A função `sellLoot` dispara `sellAllLoot(current, content)` internamente de forma silenciosa, sem abrir nenhuma janela modal. Na versão web desktop (`BottomDock.tsx`), o botão chama `onOpenQuickSell={() => setQuickSellOpen(true)}`, abrindo o componente `QuickSellWindow`.

## 🎯 Escopo de Implementação
1. **Conexão da Ação do Botão Flutuante:**
   - Em `GamePrototype.tsx`, alterar `onQuickSell={sellLoot}` para `onQuickSell={() => setQuickSellOpen(true)}`.
2. **Acesso Secundário via Menu Hambúrguer:**
   - Adicionar prop `onOpenQuickSell?: () => void;` em `MobileMenuDrawer.tsx`.
   - Adicionar item "Venda Rápida de Loot" no Menu Hambúrguer com ícone Lineart SVG de saco de moedas/ouro.
   - Conectar `onOpenQuickSell={() => setQuickSellOpen(true)}` na renderização de `MobileMenuDrawer` em `GamePrototype.tsx`.
3. **Ergonomia e Confiabilidade de Toque Mobile no `QuickSellWindow.tsx`:**
   - Adicionar `onTouchEnd` no botão de fechar ✕ do `QuickSellWindow` (`onTouchEnd={(e) => { e.stopPropagation(); onClose(); }}`).
   - Adicionar `onTouchEnd` nos cards de itens para seleção ágil e sem delay no celular.
   - Adicionar `onTouchEnd` nos botões "Marcar Todos", "Desmarcar Todos", "Cancelar" e "Vender por X gp".
   - Assegurar que `inventory-window-overlay` possua `z-index: 100000` em `app/globals.css`, ficando perfeitamente sobreposto ao HUD móvel e barras de navegação.
4. **Validação & Testes:**
   - Rodar `npm run typecheck` e garantir 0 erros de tipagem.
   - Rodar testes unitários para o fluxo de QuickSell.
   - Deploy automático na VPS com `node scripts/deploy.mjs --phase 249`.

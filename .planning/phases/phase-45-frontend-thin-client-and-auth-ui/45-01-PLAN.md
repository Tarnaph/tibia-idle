# Phase 45-01 PLAN: Refatoração do Frontend para Colyseus.js Client & Telas de Auth/Admin

## Objectives
1. Integrate `colyseus.js` client SDK into the web frontend (`apps/web/lib/colyseusClient.ts` / `GameClientNetworkManager.ts`).
2. Build Tibia 11 styled authentication and character management pages:
   - Login & Registration UI (`app/auth/login/page.tsx` & `app/auth/register/page.tsx` or modal components).
   - Character Selection & Creation Screen (`app/game/characters/page.tsx` or modal overlay) with vocation previews (Knight, Paladin, Sorcerer, Druid), name validation, and "Enter Game" button.
3. Integrate `@colyseus/monitor` and GM Admin controls (`app/admin/page.tsx` / GM panel).
4. Refactor `ThaisCityArena.tsx`, `PixiArena.tsx`, `GamePrototype.tsx` to act as a pure thin client:
   - Send movement (`room.send('move', { dir })`), combat spells (`room.send('castSpell', { spellId })`), attacks (`room.send('attack', { targetId })`), and chat (`room.send('chat', { text, channel })`).
   - Listen to Colyseus state updates (`players.onAdd`, `players.onRemove`, `players.onChange`) and render remote/local players using `VisualMotionTrack` at smooth 60 FPS.
   - Listen to `combat_event` messages and render floating damage numbers and visual spell effects.
5. Create comprehensive test suite `tests/phase45-frontend-thin-client-and-auth-ui.test.ts`.
6. Ensure 0 TypeScript errors (`npm run typecheck`) and 100% test pass rate (`npm run test`).

## Proposed Changes

### 1. Network Manager & Colyseus Client SDK Integration
- Create `apps/web/lib/colyseusClient.ts` establishing `colyseus.js` Client connection wrapper.
- Create `GameClientNetworkManager` class to manage joining `thais_city` room with JWT token & character ID, handling room events and callbacks.

### 2. Tibia 11 Auth & Character Selection/Creation UI
- Create `apps/web/components/auth/TibiaLoginForm.tsx` & `TibiaRegisterForm.tsx` matching authentic Tibia 11 dark/gold UI styling.
- Create `apps/web/components/auth/CharacterSelectModal.tsx` listing characters from `/api/characters/list`, allowing creation of new character with vocation choices (Knight, Paladin, Sorcerer, Druid) calling `/api/characters/create`.

### 3. Admin & GM Panel Integration
- Update `app/admin/page.tsx` to include Colyseus GM controls (`/kick`, `/ban`, `/teleport`) and embedded link to `@colyseus/monitor` dashboard.

### 4. Thin Client Canvas & HUD Refactoring
- Update `ThaisCityArena.tsx` & `PixiArena.tsx` to consume Colyseus `Room<WorldState>`:
  - Register callbacks on `room.state.players` (`onAdd`, `onRemove`, `onChange`).
  - Dispatch keyboard arrow/WASD inputs to `room.send('move', { dir })`.
  - Dispatch hotbar/spell inputs to `room.send('castSpell', { spellId })` or `room.send('attack', { targetId })`.
  - Receive `combat_event` and `chat_message` notifications.

### 5. Automated Testing & Verification
- Create `tests/phase45-frontend-thin-client-and-auth-ui.test.ts` testing client state mapping, input dispatching, character creation API interaction, and auth flow.

## Verification
- Run `npm run typecheck` to verify 0 TypeScript errors.
- Run `npx vitest run tests/phase45-frontend-thin-client-and-auth-ui.test.ts` to verify 100% test pass rate.

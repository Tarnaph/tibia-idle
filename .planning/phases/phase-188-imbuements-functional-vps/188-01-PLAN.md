# Plan 188-01: Parsing nativo de imbuingslots no importEquipment.ts e content-schema

## Objective
Conectar o importador oficial `packages/realmap11-importer/src/importEquipment.ts` e `packages/content-schema` para extrair nativamente o atributo `<attribute key="imbuingslots" value="X"/>` do `realmap11/data/items/items.xml` e cruzar com as tabelas de armas/equipamentos do `realmap11/data/modules/scripts/imbuement/imbuement.lua`, populando o campo `imbuingSlots` em `content/generated/equipment.json`.

## Technical Steps
1. Atualizar o schema em `packages/content-schema/src/index.ts`:
   - Adicionar `imbuingSlots?: number;` na interface `EquipmentDefinition`.
2. Atualizar `packages/realmap11-importer/src/importEquipment.ts`:
   - No loop de atributos de cada item:
     `if (key === 'imbuingslots') imbuingSlots = numberValue(val);`
   - Se `imbuingSlots` for definido, passar para o record final.
   - Adicionar fallback para os IDs explícitos de `realmap11/data/modules/scripts/imbuement/imbuement.lua` caso o item não declare a tag no XML.
3. Executar o importador via `npm run import:content` (ou script correspondente).
4. Atualizar `getItemImbuingSlots` em `packages/domain/src/imbuements.ts` para priorizar `item.imbuingSlots` do catálogo gerado.

# Plan 188-03: Deploy na VPS 187.7.16.210, reinício de tibia-web e colyseus-server, e verificação online

## Objective
Criar script de deploy seguro `scripts/deploy-phase188-vps.mjs`, executar a atualização completa da VPS de produção (`187.7.16.210`), garantindo backup do SQLite, atualização para a última versão do `origin/main`, regeneração do bundle de produção com `npx vinext build` e reinício seguro do PM2 (`tibia-web` e `colyseus-server`), para que o usuário possa testar diretamente em `187.7.16.210:3000`.

## Technical Steps
1. Criar `scripts/deploy-phase188-vps.mjs` com:
   - Conexão SSH na VPS `187.7.16.210`.
   - Backup de segurança de `prisma/dev.db`.
   - Verificação de integridade SQLite `PRAGMA integrity_check;`.
   - `git fetch origin main && git reset --hard origin/main`.
   - `npx prisma db push --skip-generate && npx prisma generate`.
   - `npx vinext build && node scripts/patch-http-pipeline.cjs`.
   - `pm2 restart tibia-web colyseus-server && pm2 save`.
   - Verificação HTTP `curl -I -s http://127.0.0.1:3000`.
2. Executar o deploy e validar o log remoto.
3. Confirmar que o serviço está online e pronto para o usuário.

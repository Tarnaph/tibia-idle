# Phase 46-01 PLAN: Persistência PostgreSQL em Lote, Reconexão Nativa Colyseus e Testes E2E

## Objectives
1. Implement `PrismaPersistenceManager` in `packages/server/src/persistence/PrismaPersistenceManager.ts`:
   - Periodic 30-second batch auto-save of active players' position, level, HP/MP, capacity, and experience to PostgreSQL.
   - Immediate flush when a player logs out or room shuts down.
2. Implement Colyseus native reconnection in `ThaisCityRoom.ts`:
   - Catch non-consented disconnections (F5 refresh, network drop) and call `await this.allowReconnection(client, 20)`.
   - Preserve player entity state for 20 seconds during reconnection window.
3. Update `GameClientNetworkManager.ts`:
   - Store `room.id` and `room.reconnectionToken`.
   - Add `tryReconnect()` method calling `client.reconnect(roomId, reconnectionToken)`.
4. Create comprehensive E2E integration test suite `tests/phase46-postgresql-persistence-reconnection-e2e.test.ts`.
5. Ensure 0 TypeScript errors (`npm run typecheck`) and 100% test pass rate (`npm run test`).

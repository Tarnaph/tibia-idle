# Plan 74-01: Personagens Novos em Nível 1 e Verificação de Visibilidade Urbana em Thais

## Objetivo
1. **Personagens Novos em Nível 1:**
   - Garantir que qualquer novo personagem criado no jogo inicie estritamente no **Nível 1** com **0 de experiência**, respeitando os atributos canônicos de início do Tibia (150 HP, 35 MP, 400 de capacidade).
   - Atualizar todos os valores default e inicializadores nos schemas Prisma, `PlayerState` do Colyseus, `CharacterService` e salas do servidor.
2. **Verificação de Visibilidade Urbana na Cidade de Thais:**
   - Realizar uma auditoria arquitetural completa no pipeline de rede e renderização da cidade de Thais (`ThaisCityArena.tsx`, `GameClientNetworkManager.ts` e `ThaisCityRoom.ts`).
   - Verificar e garantir que os novos personagens possuam as tags e propriedades essenciais para visibilidade:
     - `inHunt: false` (condição primordial que oculta heróis em expedição de caçada).
     - `posZ: 7` (piso térreo do templo da cidade de Thais, alinhado com `curPos.z`).
     - Coordenadas canônicas de spawn: `(32369, 32241, 7)` no Templo de Thais.
     - Vocation outfit e nameplate estilizado (`p.name`, Arial 8px verde `0x67de82`, contorno escuro).

## Arquivos a serem modificados
1. `packages/auth/src/characterService.ts`:
   - Em `VOCATION_CONFIGS`: atualizar `baseHp: 150`, `baseMp: 35`, `capacity: 400` para vocações no nível 1.
   - Em `CharacterService.createCharacter`: definir `level: 1` e `experience: BigInt(0)`.
2. `prisma/schema.prisma`:
   - No modelo `Character`: atualizar defaults para `level Int @default(1)`, `experience BigInt @default(0)`, `health Int @default(150)`, `maxHealth Int @default(150)`, `mana Int @default(35)`, `maxMana Int @default(35)`, `capacity Int @default(400)`.
3. `packages/server/src/schemas/PlayerState.ts`:
   - Atualizar defaults: `level: number = 1;`, `experience: number = 0;`, `hp: number = 150;`, `maxHp: number = 150;`, `capacity: number = 400;`.
4. `packages/server/src/rooms/ThaisCityRoom.ts`:
   - Atualizar inicializador fallback para `let level = 1;` e atributos base para 150 HP / 35 MP / 400 cap.
5. `tests/phase68-full-persistence-audit.test.ts`:
   - Atualizar asserções de criação de personagem que esperavam `level: 8` e `experience: 4200` para `level: 1` e `experience: 0`.
6. `tests/phase74-new-characters-level-1.test.ts`:
   - Nova suíte de testes cobrindo a criação em nível 1 e a verificação completa das tags de visibilidade urbana em Thais.

## Critérios de Aceitação
- Novos personagens criados via `CharacterService` ou API REST iniciam com `level: 1` e `experience: 0`.
- Novos personagens possuem `inHunt: false`, `posZ: 7` e coordenadas de spawn no templo de Thais `(32369, 32241, 7)`.
- Clientes remotos em Thais renderizam o novo personagem sem filtros indevidos, exibindo o sprite da vocação e o nameplate.
- 0 erros de tipagem no `npm run typecheck`.
- 100% dos testes Vitest passando.
